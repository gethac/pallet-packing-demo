# Skill: prototype-ui
用途：按 UI 规范生成线框/高保真说明。
输入：页面分区（参数/产品/清单/三维）+ Element Plus 约束。
输出：信息架构、控件清单、空态/错态、增强版控件（动画/视角/图例）。
约束：预览组件不负责 API；文案与前端中文一致。

## UI 规范（开发须遵从）
1. Element Plus 表单+表格；主操作「计算托盘」。
2. 预览背景 #eef2f6；旋转±90、缩放步进 0.12。
3. 空态「暂无托盘/暂无数据」；超限重/超限高明确错误文案。
4. 三维组件不发起 API；页面负责取数。
5. 增强版：动画、预设视角、分层/爆炸、画布外图例、HUD（含最小支撑率）。
6. 盒=彩盒无胶带；箱=牛皮纸+胶带；按规格着色。
规范全文归档：docs/design/ui-spec.md
