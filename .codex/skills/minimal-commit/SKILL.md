# Skill: minimal-commit
来源：生产开发中反复使用的提示词——“读取rules.md 了解代码提交规则 按照最小提交原则 分批次提交代码”（2026-07-10）、
“提交代码 / 最小提交原则 不要都提交成一个 按照功能拆分”（2026-08-10 起固定使用）。
步骤：
1. 读取 rules.md；有 .codegraph 时先用 CodeGraph 梳理改动涉及的调用链。
2. 盘点前后端未提交改动，按功能点划分批次；临时产物、日志、本地配置不提交。
3. 共享文件按补丁块暂存，核对暂存区只包含本批功能。
4. 每批提交前跑定向测试 / 构建 / git diff --check。
5. 提交身份使用约定的用户名和邮箱；不推送，不动 worktree，不改写已有提交。
6. 回报：提交列表、验证结果、剩余未提交内容。
